# Blahaj News

The official newspaper website themed around the IKEA Blåhaj shark plushie.

## Features
- Fun, lighthearted news articles about the beloved blue shark
- Responsive design with IKEA-inspired blue theme
- Interactive elements

## Setup
This is a static site ready for GitHub Pages.

1. Push to a GitHub repository
2. Enable GitHub Pages from the main branch (root)
